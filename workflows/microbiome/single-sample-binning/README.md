# Single-sample binning workflow

This workflow uses paired-end reads and their corresponding assemblies, generated by any assembler, to produce metagenomic bins using multiple binning tools. Each binner uses a different approach to identify and group contigs into bins.

After binning is complete, the workflow uses one or both of the available refinement tools to combine and refine the results from the individual binners, with the goal of generating higher-quality bins.

## Inputs

- Paired-end read collection
- List of corresponding `Assembly(s)`

## Workflow logic

- Preprocess reads and assembly/assemblies for binning.
- Perform binning using multiple binners:

  - CONCOCT
  - MaxBin2
  - MetaBAT2
  - SemiBin
  - COMEBin

- Refine the resulting bins using one or both refinement tools:

  - DAS Tool
  - Binette

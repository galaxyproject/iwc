# Basic-Assembly

This workflow provides a standardized and modular approach for metagenomic assembly. It generates assemblies from paired-end short reads, with optional support for long reads.

The workflow is intentionally kept simple so that it can be used as a standalone assembly workflow or integrated as a building block into larger metagenomic analysis workflows.

Long-read input is currently only supported when using **metaSPAdes**.

## Why use this workflow?

The main purpose of this workflow is to provide a basic and reusable assembly component that can be incorporated into different metagenomic analysis workflows.

Instead of including assembler-specific steps in every workflow, this workflow provides a common assembly module that can be reused wherever metagenomic assembly is required. This helps reduce duplication between workflows and makes larger workflows easier to understand, maintain, and update.

## Workflow Logic

The workflow supports two commonly used metagenomic assemblers:

  - metaSPAdes
  - MEGAHIT

The user can select the assembler depending on the requirements of the analysis. The workflow processes the provided sequencing reads and returns the resulting assembled contigs in a standardized format that can be directly used by downstream workflows.

When metaSPAdes is selected, optional long reads can be provided in addition to the paired-end short reads. This allows long-read information to support the assembly while maintaining short reads as the primary input.

It is also possible to skip the assembly part when a custom assembly is provided. Therefore only the output of **Quast** will be the result of the workflow.

## Inputs

The required inputs for this workflow are:
  
  - Trimmed paired reads (as a list:paired Collection)
  - The chosen Assembler (Options are: MEGAHIT/metaSPAdes/Custom Assembly)
  - Minimum length of contigs for MEGAHIT, if selected (Default: 200)

The optional inputs are:

  - Trimmed nanopore reads (as a list)
  - Trimmed PacBio reads (as a list)
  - And if selected, the custom assemblies (as a list)

## Outputs

The followed outputs are generated by the workflow:

  - Not depending on the Assembler:
    - Quast HTML Report
    - Quast report (tabular)
    - Quast assembly quality report (tabular and as PDF)
    - Quast Krona chats
  - When MEGAHIT is selected:
    - MEGAHIT assemblies 
  - When metaSPAdes is selected:
    - metaSPAdes assemblies
    - metaSPAdes assembly graph
    - metaSPAdes assembly graph with scaffolds
    - metaSPAdes scaffolds
  - When custom assemblies are used:
    - a duplicated version of this input

# Genome Assembly with Hifi reads and Trio Data

Generate phased assembly based on PacBio Hifi Reads using parental Illumina data for phasing. Part of the VGP workflow suite, it needs to be run after the Trio k-mer Profiling workflow VGP2.

## Inputs

1. Species Name. Used in the workflow report.
2. Assembly Name. Used in the workflow report.
3. Hifi long reads [fastq]
4. Concatenated Illumina reads : Paternal [fastq]
5. Concatenated Illumina reads : Maternal [fastq]
6. K-mer database [meryldb] generated by VGP2 workflow.
7. Paternal hapmer database [meryldb] generated by VGP2 workflow.
8. Maternal hapmer database [meryldb] generated by VGP2 workflow.
9. Bits for Bloom Filter. Change for large genomes to save memory.
10. Utilize homology information to correct trio-phasing errors (Hifiasm `--trio-dual` option). Enabled by default.
11. Database to use for Busco lineages. Recommended : latest version.
12. Lineage. Select the taxonomic lineage of the assembled species.
13. Homozygous read coverage (Estimated from the Genomescope model if not provided)
14. Genome model parameters generated by Genomescope [tabular] generated by VGP2 workflow.
15. Genome profile summary generated by Genomescope [txt] generated by VGP2 workflow.
16. Name of first haplotype
17. Name of second haplotype

## Outputs

1. Haplotype 1 assembly [fasta] and [gfa]
2. Haplotype 2 assembly [fasta] and [gfa]
3. QC: MultiQC report for HiFi reads trimming
4. QC: BUSCO report for both assemblies
5. QC: Compleasm report for both assemblies
6. QC: Merqury report for both assemblies
7. QC: Assembly statistics for both assemblies
8. QC: Nx plot for both assemblies
9. QC: Size plot for both assemblies

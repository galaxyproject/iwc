Reading workflow glyphs

Every workflow in the library has a small glyph next to its name. It isn't a logo: it's drawn from the workflow's own steps, the same graph you'd see in the Galaxy workflow editor, shrunk down to a tile.

Data comes in on the left and flows right, one column per stage of the pipeline. A slender glyph is a straight chain of steps; a wide one does many things in parallel. Workflows with the same structure get the same glyph, so related workflows look related.

The marks

  • Dataset input
  • Collection input (many datasets)
  • Tool step
  • Subworkflow
  • Final step, with results nothing else builds on

Parameter inputs aren't drawn, since they configure a workflow rather than carry data through it. On very large workflows, tool steps fade into the connecting lines so the inputs and outputs carry the shape.
